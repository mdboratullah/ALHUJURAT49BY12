## 📌 About The Project
**ALHUJURAT49BY12** is a secure, offline-first personal privacy vault designed to keep all personal notes, thoughts, sketches, and files completely private and secure. Built with robust web technologies to ensure maximum data protection and user privacy.

---

## 🚀 Features
1. **Offline-First Storage:** Keep your sensitive data safely stored without needing an active internet connection.
2. **Complete Privacy:** Zero data leakage; designed with advanced security measures.
3. **PWA Enabled:** Can be installed directly on Android and desktop devices as a native application.
4. **Lightweight & Fast:** Optimized for high performance and minimal resource usage.

---

## 🛠️ Installation & Setup Guide

### Method 1: Running Locally (For Developers)
1. Clone the repository or download the source code.
2. Open the project folder.
3. Run the `index.html` file in any modern web browser.

### Method 2: Installing as an Android App (.APK)
1. Visit the live deployment link on Netlify.
2. Open the site using a PWA-supported browser (like Google Chrome on Android).
3. Tap the browser menu and select **"Install App"** or **"Add to Home Screen"**.
4. Alternatively, use PWABuilder with the live URL to package and generate the native Android `.apk` file.
